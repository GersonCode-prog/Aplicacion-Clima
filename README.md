# App de Clima

Aplicación web para consultar el clima actual, las próximas 24 horas y el pronóstico de cualquier ciudad.

## Funciones

- Búsqueda de ciudades con sugerencias
- Clima según tu ubicación (geolocalización)
- Cambio entre °C y °F
- Fondo y partículas animadas según el estado del cielo

## Tecnologías

- HTML, CSS y JavaScript puro
- [WeatherAPI](https://www.weatherapi.com/) para los datos del clima

## Uso

Abre `index.html` en el navegador o publícalo con GitHub Pages.
